## Projetos

### FluxoBoard · painel financeiro com quadro Kanban

Organizar contas a pagar exigia planilha: sem histórico de status, sem fluxo de
caixa, sem meta de economia acompanhada. React 18 e Vite no front, Node.js e Prisma
no back, Tailwind para a interface e JWT para autenticação. Drag & drop acessível,
CRUD com filtros combinados e metas com barras de progresso. Monorepo com CI,
CodeQL e licença MIT.

`React 18` · `Vite` · `Tailwind` · `Node.js` · `Prisma` · `Zod`

[Código](https://github.com/rafaelsavioli/Projeto_002)

### HazeWeb · sistema de gestão em produção

Sistema que desenvolvo na HazeFlow, rodando para clientes reais: **23 telas e 26
APIs**. Front-end em HTML, CSS e JavaScript sem framework; back em PHP e MySQL com
autenticação e controle de sessão.

Na auditoria encontrei um vazamento real: um usuário enxergava os leads de outro.
Corrigi com filtros de dono em todas as consultas e verificação de linhas afetadas
no helper de banco. Esse tipo de bug só aparece com o sistema em uso de verdade.

`HTML` · `CSS` · `JavaScript` · `PHP` · `MySQL`

### Visual Analyser · paleta e tom de pele no navegador

Analisador que roda 100% no cliente. Extrai pixels com Canvas API, calcula
colorimetria e monta a paleta dominante por median cut — sem API externa e sem
mandar a foto para servidor nenhum. Um quiz pontua o resultado e define o estilo
pessoal.

`JavaScript` · `Canvas API` · `Colorimetria`

[Aplicação no ar](https://rafaelsavioli.github.io/Visual_Analyser/) ·
[Código](https://github.com/rafaelsavioli/Visual_Analiser)
